BLAST — Basic Local Alignment Search Tool

🔍 Apa itu BLAST?
  • Tool pencarian sekuens di database berdasarkan kemiripan lokal
  • Menemukan sekuens yang mirip (homolog) dengan query
  • Berdasarkan algoritma Smith-Waterman yang dioptimasi
  • Output: daftar hits dengan skor & E-value
📊 Metrik Output BLAST
  • Score / Bit Score: skor alignment (lebih besar = lebih baik)
  • E-value: probabilitas hasil secara kebetulan (lebih kecil = lebih signifikan)
  • Identity %: persentase posisi identik
  • Coverage %: panjang query yang tercakup alignment
Varian BLASTQueryDatabaseKegunaan
blastnNucleotideNucleotideCari sekuens DNA/RNA mirip
blastpProteinProteinCari protein homolog
blastxNucleotide (translated)ProteinTranslasi DNA lalu cari di protein DB
tblastnProteinNucleotide (translated)Cari ORF di genom
tblastxNucleotide (translated)Nucleotide (translated)Bandingkan dua genom secara protein
Jebakan UAS: E-value 1e-50 LEBIH SIGNIFIKAN dari 1e-5 karena nilainya lebih kecil. E-value < 0.001 umumnya dianggap signifikan secara statistik.

Database Access — NCBI & Cara Kerja

  • Buka https://www.ncbi.nlm.nih.gov/ → pilih database (GenBank, PubMed, dll.)
  • Masukkan Accession Number (contoh: NM_007294) di search box → klik Search
  • Klik sequence → pilih Send to → File → Format: FASTA untuk download
  • Gunakan BLAST di NCBI: paste FASTA query → pilih database → Run BLAST
  • Baca hasil: lihat E-value, Identity %, dan Description hits teratas
  • Untuk akses programatik: gunakan Biopython Entrez atau REST API NCBI E-utilities

Pairwise Sequence Alignment

Global Alignment (Needleman-Wunsch), Local Alignment (Smith-Waterman), Identity Score, dan analisis terkait.

Global vs Local Alignment

🌐 Global Alignment (Needleman-Wunsch)
  • Menyelaraskan seluruh panjang kedua sekuens
  • Cocok untuk sekuens serupa panjangnya
  • Digunakan saat sekuens diduga homolog penuh
  • Seluruh sekuens harus ter-align (dari ujung ke ujung)
  • Contoh use: membandingkan gen ortolog dua spesies
🎯 Local Alignment (Smith-Waterman)
  • Mencari sub-region terbaik dari kedua sekuens
  • Cocok untuk sekuens berbeda panjang atau berbeda domain
  • Digunakan untuk menemukan domain konservatif
  • Skor tidak bisa negatif → diset ke 0
  • Contoh use: menemukan motif protein dalam sekuens panjang

Scoring System — Dasar Perhitungan

KondisiSkor UmumPenjelasan
Match+1 atau +2Basa/asam amino identik di posisi yang sama
Mismatch−1 atau −1Basa/asam amino berbeda di posisi yang sama
Gap Open−2 atau −8Penalti awal membuka gap (insertion/deletion)
Gap Extend−1 per posisiPenalti tambahan per perpanjangan gap
Identity Score = (Jumlah posisi identik) / (Panjang alignment) × 100%
Similarity Score termasuk posisi yang similar (misal: asam amino dengan sifat kimia mirip), bukan hanya identik.

⚙️ Needleman-Wunsch — Perhitungan Step-by-Step

Contoh: align Seq A = AGCT dan Seq B = AGT
Scoring: Match = +1, Mismatch = −1, Gap = −2

📐 Step 1 — Inisialisasi Matriks DP

Buat matriks (len_A+1) × (len_B+1). Isi baris 0 dan kolom 0 dengan gap penalties: F(i,0) = i × gap_penalty, F(0,j) = j × gap_penalty

–AGCT
–0−2−4−6−8
A−2????
G−4????
T−6????
📐 Step 2 — Isi Matriks (Recurrence Relation)

Untuk setiap sel F(i,j), ambil MAXIMUM dari 3 kemungkinan:

F(i,j) = MAX of: ① F(i-1, j-1) + score(A[i], B[j]) ← diagonal (match/mismatch) ② F(i-1, j) + gap_penalty ← dari atas (gap di B) ③ F(i, j-1) + gap_penalty ← dari kiri (gap di A)
1
F(1,1) — A vs A (MATCH) ① F(0,0) + score(A,A) = 0 + 1 = +1 ② F(0,1) + gap = −2 + (−2) = −4 ③ F(1,0) + gap = −2 + (−2) = −4 → MAX(+1, −4, −4) = +1 ✓
2
F(1,2) — A vs G (MISMATCH) ① F(0,1) + score(A,G) = −2 + (−1) = −3 ② F(0,2) + gap = −4 + (−2) = −6 ③ F(1,1) + gap = +1 + (−2) = −1 → MAX(−3, −6, −1) = −1 ✓
3
F(1,3) — A vs C (MISMATCH) ① F(0,2) + score(A,C) = −4 + (−1) = −5 ② F(0,3) + gap = −6 + (−2) = −8 ③ F(1,2) + gap = −1 + (−2) = −3 → MAX(−5, −8, −3) = −3 ✓
4
F(1,4) — A vs T (MISMATCH) ① F(0,3) + score(A,T) = −6 + (−1) = −7 ② F(0,4) + gap = −8 + (−2) = −10 ③ F(1,3) + gap = −3 + (−2) = −5 → MAX(−7, −10, −5) = −5 ✓
5
F(2,1) — G vs A (MISMATCH) ① F(1,0) + score(G,A) = −2 + (−1) = −3 ② F(1,1) + gap = +1 + (−2) = −1 ③ F(2,0) + gap = −4 + (−2) = −6 → MAX(−3, −1, −6) = −1 ✓
6
F(2,2) — G vs G (MATCH) ① F(1,1) + score(G,G) = +1 + 1 = +2 ② F(1,2) + gap = −1 + (−2) = −3 ③ F(2,1) + gap = −1 + (−2) = −3 → MAX(+2, −3, −3) = +2 ✓
7
F(2,3) — G vs C (MISMATCH) ① F(1,2) + score(G,C) = −1 + (−1) = −2 ② F(1,3) + gap = −3 + (−2) = −5 ③ F(2,2) + gap = +2 + (−2) = 0 → MAX(−2, −5, 0) = 0 ✓
8
F(2,4) — G vs T (MISMATCH) ① F(1,3) + score(G,T) = −3 + (−1) = −4 ② F(1,4) + gap = −5 + (−2) = −7 ③ F(2,3) + gap = 0 + (−2) = −2 → MAX(−4, −7, −2) = −2 ✓
9
F(3,1) — T vs A (MISMATCH) ① F(2,0) + score(T,A) = −4 + (−1) = −5 ② F(2,1) + gap = −1 + (−2) = −3 ③ F(3,0) + gap = −6 + (−2) = −8 → MAX(−5, −3, −8) = −3 ✓
10
F(3,2) — T vs G (MISMATCH) ① F(2,1) + score(T,G) = −1 + (−1) = −2 ② F(2,2) + gap = +2 + (−2) = 0 ③ F(3,1) + gap = −3 + (−2) = −5 → MAX(−2, 0, −5) = 0 ✓
11
F(3,3) — T vs C (MISMATCH) ① F(2,2) + score(T,C) = +2 + (−1) = +1 ② F(2,3) + gap = 0 + (−2) = −2 ③ F(3,2) + gap = 0 + (−2) = −2 → MAX(+1, −2, −2) = +1 ✓
12
F(3,4) — T vs T (MATCH) ← Skor Akhir! ① F(2,3) + score(T,T) = 0 + 1 = +1 ② F(2,4) + gap = −2 + (−2) = −4 ③ F(3,3) + gap = +1 + (−2) = −1 → MAX(+1, −4, −1) = +1 ← OPTIMAL SCORE

A−2+1−1−3−5

📐 Step 3 — Traceback (dari F(3,4) ke F(0,0))
1
F(3,4)=+1 berasal dari F(2,3)=0 + score(T,T)=1 → diagonal (T vs T = MATCH)
2
F(2,3)=0 berasal dari F(2,2)=+2 + gap=(−2) = 0 → kiri (gap di B, skip C di A)
3
F(2,2)=+2 berasal dari F(1,1)=+1 + score(G,G)=1 → diagonal (G vs G = MATCH)
4
F(1,1)=+1 berasal dari F(0,0)=0 + score(A,A)=1 → diagonal (A vs A = MATCH)

Cara Hitung Identity Score:
Identity % = (Jumlah posisi IDENTIK) ÷ (Total panjang alignment) × 100%
Contoh di atas: 3 match dari 4 posisi = 3/4 × 100% = 75%

Multiple Sequence Alignment (MSA)

Theory, Basic Analysis dari Slide — Kasus MSA hingga Distance Tree, Pandemic, dan Vaccine Development.

Apa itu MSA?

MSA (Multiple Sequence Alignment) adalah proses menyelaraskan 3 atau lebih sekuens secara bersamaan untuk mengidentifikasi wilayah konservatif, divergen, dan hubungan evolusioner.

🎯 Tujuan MSA
  • Mengidentifikasi conserved regions (wilayah penting fungsional)
  • Membangun phylogenetic tree
  • Prediksi struktur protein
  • Desain primer PCR universal
  • Identifikasi mutasi/variasi antar strain
🛠️ Tools MSA Populer
  • ClustalW / ClustalOmega — progressive alignment
  • MUSCLE — cepat, akurat untuk protein
  • MAFFT — iterative refinement
  • T-Coffee — high accuracy, lambat
  • Biopython AlignIO — analisis programatik

Progressive Alignment (ClustalW) — Algoritma

  • Hitung pairwise distance — semua pasangan sekuens di-align, dihitung skor similarity
  • Buat distance matrix — konversi skor ke jarak (distance = 1 − similarity)
  • Buat Guide Tree — menggunakan UPGMA atau NJ (Neighbor Joining) dari distance matrix
  • Progressive alignment — align sekuens/grup mengikuti guide tree dari yang paling similar ke yang paling berbeda
  • Output — MSA final dalam format CLUSTAL, FASTA, atau PHYLIP

Aplikasi MSA — Kasus Pandemi & Vaksin

🦠 MSA untuk Pandemi
  • MSA sekuens virus dari berbagai wilayah → tracking mutasi varian
  • Identifikasi conserved epitopes yang tidak bermutasi → target vaksin
  • Membangun phylogenetic tree untuk tracing asal-usul virus
  • Contoh: MSA 1000+ sekuens SARS-CoV-2 dari GISAID
💉 MSA untuk Desain Vaksin
  • Identifikasi highly conserved regions sebagai antigen target
  • Pilih epitopes yang tidak mengalami mutasi antar varian
  • Consensus sequence dari MSA → desain antigen vaksin
  • MSA protein Spike SARS-CoV-2: konservasi di receptor binding domain
Key Concept: "Conserved" = posisi dalam MSA yang sama (atau sangat mirip) di semua/mayoritas sekuens → menandakan fungsi esensial (seleksi purifying). "Variable" = posisi berbeda-beda → tekanan seleksi rendah atau adaptasi.

Evolutionary Biology

Theory dan Basic Analysis dari Slide — Dasar evolusi molekuler yang mendasari analisis phylogenetic.

Teori Evolusi Molekuler — Konsep Kunci

KonsepDefinisiRelevansi ke Bioinformatika
HomologSekuens yang berasal dari nenek moyang yang samaDasar semua analisis alignment & phylogeny
OrthologGen homolog di spesies berbeda akibat spesiasiPerbandingan fungsi gen antar spesies

Model Substitusi Nukleotida

Jukes-Cantor (JC69)
  • Model paling sederhana
  • Asumsi: semua substitusi terjadi dengan laju yang SAMA
  • 4 nukleotida dengan frekuensi yang SAMA (25% each)
  • Koreksi: d = −3/4 × ln(1 − 4/3 × p)
  • p = proporsi posisi berbeda (observed distance)
Kimura 2-Parameter (K2P)
  • Membedakan transitions (Ti) dan transversions (Tv)
  • Transitions (A↔G, C↔T) lebih sering terjadi
  • Ti/Tv ratio biasanya 2:1 atau lebih
  • Lebih realistis dari JC69
  • Umum digunakan untuk data DNA
Transition vs Transversion:
• Transition: Purine↔Purine (A↔G) atau Pyrimidine↔Pyrimidine (C↔T)
• Transversion: Purine↔Pyrimidine (A/G ↔ C/T)
Transitions lebih sering karena perubahan kimia lebih kecil.

Konsep Distance (Jarak Evolusioner)

Menghitung Observed Distance (p)
1
Hitung jumlah perbedaan posisi antara dua sekuens dari alignment Seq 1: ACGTTAGC | Seq 2: ACGCTAGC Posisi berbeda: posisi 4 (T vs C) = 1 perbedaan
2
Hitung observed distance p: p = jumlah perbedaan / panjang alignment = 1/8 = 0.125
3
Koreksi dengan JC69 untuk multiple hits: d = −(3/4) × ln(1 − (4/3) × p) d = −0.75 × ln(1 − 1.333 × 0.125) d = −0.75 × ln(1 − 0.1667) = −0.75 × ln(0.8333) d = −0.75 × (−0.1823) ≈ 0.1368

Phylogenetic Tree — UPGMA & WPGMA

Metode clustering untuk membangun pohon filogenetik dari distance matrix — dengan perhitungan SANGAT detail step-by-step.

UPGMA vs WPGMA — Perbedaan Utama

UPGMA (Unweighted Pair Group Method with Arithmetic Mean)
  • Merata-ratakan jarak dengan mempertimbangkan ukuran grup
  • Formula: d(AB,C) = (|A|·d(A,C) + |B|·d(B,C)) / (|A|+|B|)
  • |A| = jumlah taksa dalam grup A
  • Menghasilkan ultrametric tree (jarak akar ke semua daun sama)
  • Asumsi: constant evolutionary rate (molecular clock)
WPGMA (Weighted Pair Group Method with Arithmetic Mean)
  • Merata-ratakan jarak TANPA mempertimbangkan ukuran grup
  • Formula: d(AB,C) = (d(A,C) + d(B,C)) / 2
  • Ukuran grup tidak diikutsertakan dalam perhitungan
  • Memberikan bobot sama untuk setiap sub-kelompok
  • Kadang lebih robust jika ukuran sampel tidak seimbang
Mudah Bingung? Ingat: meski namanya "Weighted" WPGMA, justru TANPA bobot ukuran. "Unweighted" UPGMA justru PAKAI bobot ukuran (n). Nama historis memang membingungkan!

1

Branch length ke A = d(A,B)/2 = 4/2 = 2.0
Branch length ke B = d(A,B)/2 = 4/2 = 2.0
(Kedua taksa bergabung pada tinggi 2.0 dari akar masing-masing)
3
Hitung jarak (AB) ke C menggunakan UPGMA:
|A|=1, |B|=1, |AB|=|A|+|B|=2
d(AB,C) = (|A|×d(A,C) + |B|×d(B,C)) / (|A|+|B|) d(AB,C) = (1×8 + 1×8) / (1+1) = 16/2 = 8.0
4
Hitung jarak (AB) ke D menggunakan UPGMA:
d(AB,D) = (|A|×d(A,D) + |B|×d(B,D)) / (|A|+|B|) d(AB,D) = (1×8 + 1×8) / (1+1) = 16/2 = 8.0

Branch length (CD) dari root: Tinggi root − Tinggi node (CD) = 4.0 − 3.0 = 1.0
✅ Phylogenetic Tree UPGMA — Newick Format & Interpretasi
Newick: ((A:2,B:2):2,(C:3,D:3):1); Struktur pohon (dari bawah ke atas): ┌──2.0──A ← Branch length A ──2.0──┤ (Node AB bergabung di tinggi 2.0) | └──2.0──B | ───(root=4.0) | ┌──3.0──C ──1.0──┤ (Node CD bergabung di tinggi 3.0) └──3.0──D Tinggi node (AB) = 2.0 → d(A,B)/2 = 4/2 Tinggi node (CD) = 3.0 → d(C,D)/2 = 6/2 Tinggi root = 4.0 → d(AB,CD)/2 = 8/2
Interpretasi: A dan B lebih dekat satu sama lain (divergensi lebih awal, waktu lebih dekat). C dan D juga berpasangan. Kedua pasang bergabung di root, menandakan keempat taksa memiliki nenek moyang bersama pada waktu 4.0 (unit waktu/jarak).

📐 ITERASI 1 — WPGMA (TANPA bobot ukuran)
1
Cari minimum: d(A,B) = 4 ← MINIMUM (sama seperti UPGMA)
2
Gabungkan A dan B → (AB), tinggi = 4/2 = 2.0
3
Hitung d(AB,C) menggunakan WPGMA:
Formula WPGMA: d(AB,C) = (d(A,C) + d(B,C)) / 2 ← TIDAK ada |A|, |B| d(AB,C) = (8 + 8) / 2 = 16/2 = 8.0
4
Hitung d(AB,D) menggunakan WPGMA:
d(AB,D) = (d(A,D) + d(B,D)) / 2 = (8 + 8) / 2 = 8.0
Pada contoh ini hasilnya SAMA dengan UPGMA karena |A|=|B|=1 dan d(A,C)=d(B,C). Perbedaan muncul ketika ukuran grup berbeda!
📐 ITERASI 2 — WPGMA
1
Cari minimum: d(C,D)=6 ← MINIMUM. Gabungkan C dan D → (CD), tinggi = 3.0
2
Hitung d(AB,CD) menggunakan WPGMA:
Formula: d(AB,CD) = (d(AB,C) + d(AB,D)) / 2 ← Hanya rata-rata biasa d(AB,CD) = (8.0 + 8.0) / 2 = 8.0
📐 ITERASI 3 — Gabungkan (AB) dan (CD)
1
Tinggi root = d(AB,CD)/2 = 8/2 = 4.0
2
Branch length (AB) dari root = 4.0 − 2.0 = 2.0
3
Branch length (CD) dari root = 4.0 − 3.0 = 1.0
Kapan UPGMA dan WPGMA memberikan hasil BERBEDA?
Misalkan: d(A,C)=6, d(B,C)=10, d(A,D)=6, d(B,D)=10, |A|=1, |B|=3
• UPGMA: d(AB,C) = (1×6 + 3×10)/(1+3) = (6+30)/4 = 9.0
• WPGMA: d(AB,C) = (6 + 10)/2 = 8.0
UPGMA memberi bobot lebih pada B karena grupnya lebih besar!
Ringkasan Perbedaan UPGMA vs WPGMA:
| | UPGMA | WPGMA |
|Bobot| Proporsional terhadap ukuran grup | Sama rata (1/2) |
|Formula| (nA×dAC + nB×dBC)/(nA+nB) | (dAC + dBC)/2 |
|Hasil sama jika| Semua grup ukurannya sama | Selalu berbeda jika ukuran berbeda |
|Preferred| Ketika sample sizes berbeda | Saat ingin equal weighting per clade |
